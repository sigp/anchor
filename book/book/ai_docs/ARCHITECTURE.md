# Book Component Architecture

## Component Type
Static documentation website generated by mdBook

## File Organization

### Generated Content
- **HTML pages**: Individual documentation pages with consistent layout
- **Static assets**: CSS, JavaScript, fonts, and images
- **Search infrastructure**: Client-side search with indexed content

### Key Directories
```
book/
├── *.html              # Generated documentation pages
├── css/                # Stylesheets (theme + custom)
├── FontAwesome/        # Icon font assets
├── fonts/              # Typography assets
├── src/                # Source markdown files
│   ├── SUMMARY.md      # Book structure
│   └── *.md           # Documentation content
└── ai_docs/           # AI-generated documentation
```

## Build Dependencies
- **mdBook**: Static site generator for documentation
- **Mermaid.js**: Diagram rendering
- **ElasticLunr**: Client-side search functionality
- **Font Awesome**: Icon fonts
- **Highlight.js**: Syntax highlighting

## Theming
- Uses mdBook's default theme with custom CSS overrides
- Responsive design for mobile and desktop
- Dark/light theme support
- Custom styling in `css/custom.css`

## Interactive Features
- Client-side search
- Collapsible navigation
- Syntax highlighting for code blocks
- Mermaid diagram support
- Print-friendly formatting
