## Keysplit Command

The `keysplit` command is used to split validator keys for distributed validation on the SSV network.

```bash
anchor keysplit <SUBCOMMAND> [OPTIONS]
```

Where `<SUBCOMMAND>` is one of:

- `onchain` - Utilize onchain data to split the key
- `manual` - Split the key by manually providing data

{/* CLI_REFERENCE_START */}
### onchain Subcommand

Utilize onchain data to split the key

```bash
anchor onchain onchain [OPTIONS] --owner <ADDRESS> --output-path <OUTPUT PATH> --operators <IDS> --rpc <ENDPOINT>
```

| Option | Description | Default |
| --- | --- | --- |
| `--keystore-paths <PATH>` | Path(s) to the validator keystore file |  |
| `--password-file <PATH>` | Path to a file containing the password for the validator keystore. If omitted, the password will be prompted for. |  |
| `--owner <ADDRESS>` | EOA address that owns the validator |  |
| `--output-path <OUTPUT PATH>` | Path for output |  |
| `--operators <IDS>` | Operators to split key among |  |
| `--rpc <ENDPOINT>` | RPC endpoint to access L1 data |  |

### manual Subcommand

Split the key by manually providing data

```bash
anchor manual manual [OPTIONS] --owner <ADDRESS> --output-path <OUTPUT PATH> --operators <IDS> --nonce <NONCE> --public-keys <KEYS>...
```

| Option | Description | Default |
| --- | --- | --- |
| `--keystore-paths <PATH>` | Path(s) to the validator keystore file |  |
| `--password-file <PATH>` | Path to a file containing the password for the validator keystore. If omitted, the password will be prompted for. |  |
| `--owner <ADDRESS>` | EOA address that owns the validator |  |
| `--output-path <OUTPUT PATH>` | Path for output |  |
| `--operators <IDS>` | Operators to split key among |  |
| `--nonce <NONCE>` | Nonce for the owner address |  |
| `--public-keys <KEYS>` | RSA public keys for the operators |  |

{/* CLI_REFERENCE_END */}

#### Examples

Manual key splitting

```bash
anchor keysplit manual \
  --keystore-paths /path/to/validator_keystore.json \
  --password-file /path/to/password.txt \
  --owner 0x123abc... \
  --operators 1,2,3,4 \
  --output-path /path/to/output.json \
  --nonce 0 \
  --public-keys key1 key2 key3 key4 \
  --network hoodi
```

Onchain key splitting

```bash
anchor keysplit onchain \
  --keystore-paths /path/to/validator_keystore.json \
  --password-file /path/to/password.txt \
  --owner 0x123abc... \
  --operators 1,2,3,4 \
  --output-path /path/to/output.json \
  --rpc https://eth-mainnet.provider.com \
  --network mainnet
```

These commands will generate a json file to be uploaded to the SSV network webapp when
registering a validator.
