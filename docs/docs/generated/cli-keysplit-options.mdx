#### onchain Subcommand

Utilize onchain data to split the key

##### Shared Keygen Options

| Option | Description | Default |
| --- | --- | --- |
| `--keystore-paths <PATH>` | Path(s) to the validator keystore file |  |
| `--password-file <PATH>` | Path to a file containing the password for the validator keystore. If omitted, the password will be prompted for. |  |
| `--owner <ADDRESS>` | EOA address that owns the validator | Required |
| `--output-path <OUTPUT PATH>` | Path for output | Required |
| `--operators <IDS>` | Operators to split key among | Required |

##### Additional Options

| Option | Description | Default |
| --- | --- | --- |
| `--rpc <ENDPOINT>` | RPC endpoint to access L1 data | Required |
